# SIM-TANI

SIM-TANI adalah backend API Laravel untuk Sistem Informasi Manajemen Kelompok Tani. Aplikasi ini menangani autentikasi anggota/admin, pendaftaran kompetensi pekerjaan, penjadwalan kegiatan, penugasan, presensi, penggajian, dan permintaan perubahan tugas.

## Fitur Utama

- Autentikasi yang aman dengan Laravel Sanctum
- Role hanya `admin` dan `anggota`
- Manajemen jenis pekerjaan dan kompetensi anggota
- Kegiatan dan otomatisasi jadwal berdasarkan kriteria kemampuan
- Penugasan, validasi, presensi, dan upah
- Permintaan perubahan tugas/tukar jadwal
- Dashboard ringkas untuk admin dan anggota

## Persyaratan

- PHP 8.4+
- Composer
- MySQL atau SQLite untuk pengujian lokal

## Instalasi

```bash
composer install
cp .env.example .env
php artisan key:generate
php artisan migrate --seed
```

## Endpoint Utama

Semua endpoint API berada di bawah `/api` dan menggunakan token Bearer dari Laravel Sanctum.

### Autentikasi

- `POST /api/auth/login`
- `POST /api/auth/logout`
- `GET /api/auth/me`

### Admin

- `GET /api/users`
- `GET /api/job-types`
- `POST /api/activities`
- `POST /api/activities/{activity}/generate-schedule`
- `GET /api/assignments`
- `POST /api/assignments/{assignment}/verify`
- `GET /api/dashboard`

### Anggota

- `GET /api/my/tasks`
- `POST /api/my/tasks/{assignment}/start`
- `POST /api/my/tasks/{assignment}/complete`
- `GET /api/my/attendance`
- `POST /api/my/change-requests`
- `GET /api/my/wages`
